Week 1 - Strategic Planning and Data Exploration in Logistics

This folder contains the Week 1 work for the NSDC Logistics Data Analyst Internship.

The task focuses on defining a logistics scenario, identifying key performance indicators (KPIs), researching relevant logistics data, planning a data analysis workflow, and illustrating the proposed approach using Python.

Key Areas

- Logistics problem definition
- KPI identification
- Data and literature research
- Data science methodology
- Strategic analysis roadmap
- Python code illustration
- Expected outcomes and recommendations
