# Week 2 - Data Collection, Cleaning and Preprocessing for Logistics Analysis

This folder contains the Week 2 work for the NSDC Logistics Data Analyst Internship.

## Objective

The task focuses on preparing logistics data for reliable analysis by applying data collection, cleaning, missing-value handling, outlier detection, feature engineering, and standardization techniques using Python.

## Work Completed

- Selected a publicly available logistics delivery dataset.
- Inspected dataset structure and data quality.
- Checked and handled missing values.
- Removed duplicate records.
- Converted data types where required.
- Identified potential outliers using the IQR method.
- Created delay-related features.
- Applied feature standardization using Scikit-learn.
- Prepared the cleaned dataset for further analysis and machine learning.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

- `Week 2 Report.docx` — Week 2 report

## Dataset

A publicly available logistics delivery dataset was used as the reference dataset for this academic project. The original dataset is not redistributed in this repository.

## Outcome

The preprocessing workflow demonstrates how raw logistics data can be transformed into a cleaner and more consistent dataset suitable for exploratory analysis and future predictive modeling.
