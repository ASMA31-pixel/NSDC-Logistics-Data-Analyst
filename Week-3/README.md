# Week 3 - Advanced Data Analysis and Visualization in Logistics

This folder contains the Week 3 work for the NSDC Logistics Data Analyst Internship.

## Objective

The task focuses on performing exploratory data analysis (EDA) and creating visualizations to identify patterns, trends, relationships, and important insights in logistics data.

## Work Completed

- Performed exploratory data analysis on logistics data.
- Analyzed delivery time, distance, cost, package weight, and delay-related variables.
- Created charts and visualizations to understand data patterns.
- Studied relationships between logistics variables.
- Identified important trends and potential factors affecting delivery delays.
- Derived actionable insights for logistics decision-making.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files

- `NSDC_Logistics_Data_Analyst_Week_3_Report.docx` — Week 3 report
- `logistics_data_analysis.py` — Python analysis script
- `README.md` — Documentation for Week 3

## Outcome

The analysis provides a better understanding of logistics performance and helps identify factors that may influence delivery delays and operational efficiency.
