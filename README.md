# NSDC Logistics Data Analyst Internship

This repository contains my work completed during the NSDC Logistics Data Analyst Internship.

The project focuses on applying Python and data analysis techniques to logistics and delivery data, covering data exploration, cleaning, preprocessing, visualization, predictive modeling, and optimization.

## Objectives

- Understand logistics and delivery data.
- Identify important logistics KPIs.
- Explore delivery-related variables and patterns.
- Clean and preprocess logistics data.
- Perform exploratory data analysis and visualization.
- Build a foundation for predictive modeling.
- Apply data-driven approaches to logistics decision-making.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- GitHub

## Weekly Work

### Week 1 — Strategic Planning and Data Exploration
- Defined the logistics analytics problem.
- Identified important KPIs.
- Researched suitable logistics datasets.
- Planned the data analysis workflow.

**Folder:** `Week-1/`

### Week 2 — Data Collection, Cleaning and Preprocessing
- Examined logistics delivery data.
- Handled missing values and duplicate records.
- Validated data types and values.
- Identified potential outliers.
- Created delay-related features.
- Applied data standardization.

**Folder:** `Week-2/`

### Week 3 — Advanced Data Analysis and Visualization
- Performed exploratory data analysis.
- Analyzed logistics variables and delivery patterns.
- Created visualizations.
- Studied relationships between variables.
- Identified potential factors affecting delivery delays.

**Folder:** `Week-3/`

### Week 4 — Predictive Modeling and Optimization
- Prepared data for predictive modeling.
- Built a delivery-delay classification model.
- Evaluated model performance.
- Analyzed feature importance.
- Explored optimization strategies for logistics operations.

**Folder:** `Week-4/`
